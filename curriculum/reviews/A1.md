# A1 accuracy review

- **Date:** 2026-09-26
- **Reviewer:** Claude (agent). Not a native-speaker review; see "Limits" below.
- **Method:** Every A1 lesson was dumped to plain text (explanations, tables, vocabulary,
  every example sentence, and every exercise with its answer key and options) and read
  line by line. For each item I checked: grammar and spelling (accents included); that
  the Spanish is natural in Latin American usage; that the English translation matches;
  that every answer key is correct and that the obviously-correct alternatives a learner
  might type are accepted; that multiple-choice distractors are actually wrong; and that
  explanations are accurate.
- **Lessons reviewed:** a1-01, a1-02, a1-03, a1-04, a1-05, a1-06, a1-07, a1-08, a1-09,
  a1-10, a1-11, a1-12, a1-13, a1-14, a1-15, a1-16, a1-17, a1-18, a1-19, a1-20, a1-21,
  a1-22, a1-23, a1-24, a1-25, a1-26, a1-27, a1-28, a1-29, a1-30.

## Findings and fixes

- a1-06: a multiple-choice item marked *Tengo veinte.* as wrong, but it is perfectly natural as an answer about age → replaced that distractor with *Estoy veinte años.* and added an explanation.
- a1-26: the pronoun table showed *El libro? Lo leo.* etc. without the opening *¿* → added the opening question marks to all four rows.
- a1-26, a1-28: explanations nested bold inside italic (*Compro **el pan***), which rendered as broken HTML in the app → rewrote both explanations without nested markup, and made the app's renderer strip tags from speakable text so this can't break the page again.
- a1-10, a1-19, a1-21, a1-26: two-speaker exchanges were written as one sentence (*Me gusta el cine. A mí también.*), which reads as one person contradicting themselves → marked each turn with the Spanish dialogue dash (*—Me gusta el cine. —A mí también.*), taught the convention in a1-19, and made answer checking ignore dashes so listening drills still accept typed answers without them.
- a1-01: letter names followed only the RAE (*uve*, *uve doble*, *ye*), but most of Latin America says *ve corta / ve chica*, *be larga*, *doble ve*, *i griega* → added a note and an explanation on the *v* question.
- a1-01: the example *La música, mañana.* was not a natural sentence → replaced with *La música y el café.*
- a1-05: *El día es bonito.* is unidiomatic → replaced with *Es un día bonito.*
- a1-07: *viejo* taught for people without warning that it can sound rude → added a note recommending *mayor* for older people.
- a1-02: British "lifts" in an explanation for a US-English learner → changed to "elevators".

## Checked and found correct (no change)

- All verb paradigms (ser, estar, tener, ir, regular -ar/-er/-ir, stem-changing, yo-irregulars, reflexives, gerunds) and all conjugated forms in answer keys.
- All number spellings (0–1,000,000), time expressions (*es la una / son las…*, *y cuarto*, *menos cuarto*, *cuarto para*), dates and months.
- Gender/article facts (*el día, el mapa, la mano, el agua*), plural rules, *al/del*, adjective agreement and apocope (*buen, mal, gran*).
- Regional notes (*carro/coche, departamento/piso, recámara, cuadra/manzana, sigue derecho/todo recto, enojado/enfadado, chao/chau, dale*).

## Limits

This review is by the same system that wrote the content, so it catches errors of fact and
form better than subtle naturalness. Anything Clara flags with "I was right" in the app is
listed in Settings → Flagged answers for a later fix.
